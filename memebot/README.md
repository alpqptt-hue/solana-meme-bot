# بوت مسح وتنبيه لعملات الميم (Memecoin Scanner Bot)

ملف واحد فقط: `memebot.py`. يطبّق منهجية المستند: سيولة + تأكيد حجم + محافظ ذكية (اختياري) + فحص Honeypot/Rug، بنظام سكور من 100، مع تنبيه فوري عبر Telegram ومحاكاة صفقة ورقية (Paper) بجني أرباح متدرج.

## ⚠️ اقرأ هذا قبل أي شيء

- **البوت لا ينفذ صفقات حقيقية على السلسلة.** يرسل لك تنبيه فوري، وأنت تنفذ الشراء يدويًا بمحفظتك خلال ثوانٍ لو قررت. هذا مقصود: صفقات On-chain لا رجعة فيها، وأي خطأ برمجي بسيط = خسارة فورية ونهائية.
- **فحوصات Honeypot/Rug (honeypot.is و RugCheck.xyz) مؤشرات وليست ضمانات.** لا تعتمد عليها وحدها أبدًا. تحقق دائمًا بنفسك.
- **مكونان من السكور (تتبع نمو الحاملين + الزخم الإعلامي = 20 نقطة) غير مفعّلين افتراضيًا** لعدم وجود مصدر بيانات مجاني موثوق لهما — يظهران دائمًا 0 في السكور حتى تربطهما بمصدر بياناتك الخاص.
- **تتبع "المحافظ الذكية" (30 نقطة) يحتاج منك تزويده بعناوين محافظ فعلية** + مفتاح API مجاني من Etherscan/BscScan/Basescan. بدونها، هذا المكون = 0 دائمًا.
- عملات الميم عالية المخاطر جدًا وأغلبها ينتهي بخسارة كاملة لرأس المال. هذا أداة مساعدة وليست نصيحة استثمارية.

## الإعداد (كل شيء داخل `memebot.py` بالأعلى، قسم "EDIT YOUR SETTINGS")

أهم الإعدادات اللي غالبًا تحتاج تعدلها:

```python
CHAINS = ["solana"]                    # أو ["ethereum", "bsc", "base"]
AUTO_DISCOVER_TRENDING = True          # اكتشاف تلقائي، أو حدد عناوين بنفسك في WATCHLIST_TOKENS
ENTRY_SCORE_THRESHOLD = 60.0           # ارفعها لـ 85-90 بعد ما تفعّل تتبع المحافظ الذكية
SMART_WALLETS = {"ethereum": ["0x...", "0x..."]}   # عناوين محافظ ناجحة تتابعها
```

### مفاتيح البيئة (Environment Variables) — لا تكتبها داخل الملف
```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
ETHERSCAN_API_KEY=...      # مجاني من etherscan.io/apis
BSCSCAN_API_KEY=...        # مجاني من bscscan.com/apis
BASESCAN_API_KEY=...       # مجاني من basescan.org/apis
```

## التشغيل محليًا
```bash
pip install -r requirements.txt
python3 memebot.py --once      # دورة مسح واحدة، يطبع النتائج فقط
python3 memebot.py             # حلقة مستمرة
```

## النشر على Render (مجاني)
نفس أسلوب مشروع بوت الـ Spot السابق:

1. ارفع `memebot.py` + `requirements.txt` + `render.yaml` **في جذر مستودع GitHub** (ملف واحد فقط لبوت التداول، فلا يوجد احتمال لخبطة مجلدات هذي المرة)
2. Render → New → Web Service → اربط المستودع (يقرأ `render.yaml` تلقائيًا)
3. أو يدويًا: Build Command = `pip install -r requirements.txt`، Start Command = `gunicorn -w 1 -k gthread --threads 4 -b 0.0.0.0:$PORT memebot:app`
4. أضف متغيرات البيئة أعلاه من تبويب Environment
5. سجّل في **UptimeRobot** (مجاني) وأضف مراقب HTTP على `https://اسم-خدمتك.onrender.com/health` كل 5 دقايق (نفس طريقة بوت الـ Spot، لتفادي نوم الخدمة المجانية)

## المحفظة الوهمية (Paper Trading برصيد 1000 ريال)

البوت يبدأ برصيد وهمي **1000 ريال سعودي** ويتعامل معه كحساب حقيقي فعليًا:
- كل صفقة تاخذ نسبة من الرصيد **الحالي** (افتراضيًا 15%، عدّلها في `ALLOCATION_PCT_PER_TRADE`)
- الأرباح/الخسائر تُخصم أو تُضاف للنقدي فورًا (نفس فكرة حساب حقيقي بالضبط)
- تحويل الأسعار من دولار لريال بسعر صرف ثابت 3.75 (`USD_SAR_RATE`)

**كيف تشوف النتائج في أي وقت:**
- عبر Telegram: ملخص تلقائي كل ساعة تقريبًا (رصيد، عائد %، نسبة فوز، أفضل/أسوأ صفقة)
- عبر المتصفح: افتح `https://اسم-خدمتك.onrender.com/portfolio` ويرجع لك JSON بكل الأرقام لحظيًا

**كيف تقرر إذا البوت ناجح:**
اتركه يشتغل أسبوعين على الأقل (عملات الميم متقلبة جدًا، أسبوع وحيد مو كافي للحكم). لو `total_return_pct` موجب باستمرار مع `win_rate_pct` معقول (فوق 40-50% مع نسبة ربح/خسارة جيدة)، فالمنهجية تستاهل تجربة بمبلغ حقيقي صغير جدًا أول مرة — وليس كامل رأس المال دفعة وحدة.



كل تنبيه Telegram يوضح:
- السكور الكلي ونسبة الثقة
- كل مكون من السكور والسبب (شفاف بالكامل، ما فيه "صندوق أسود")
- عنوان التوكن للتحقق اليدوي قبل أي قرار

## الخلاصة العملية
هذا البوت **يقلل الوقت اللي تصرفه بالمسح اليدوي** ويعطيك تنبيه منظم بدل ما تراقب Twitter/Telegram كل دقيقة، لكنه **لا يغنيك عن التحقق اليدوي النهائي** قبل أي دخول فعلي، خصوصًا في عالم الميم كوين اللي فيه احتيال كثير.
